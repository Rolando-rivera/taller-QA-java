# Taller de automatización de pruebas en Java

Proyecto de integración continua, pruebas unitarias, BDD y rendimiento.

## Etapa inicial
Esta etapa contiene una calculadora con suma y resta y dos pruebas JUnit.
Requisitos: JDK 17, Maven y Git.

## Ejecutar las pruebas
Desde la carpeta donde se encuentra pom.xml, ejecutar:

```powershell
mvn clean test
```

El resultado esperado es dos pruebas ejecutadas, cero fallos y BUILD SUCCESS.
